# 🖼️ Image To Prompt

>  Transform images into detailed AI-ready prompts using Microsoft's Florence-2 Vision Language Model.

---

# 📖 Overview

**Image To Prompt** is an AI-powered web application that converts uploaded images into detailed textual prompts using **Microsoft Florence-2**, a state-of-the-art Vision Language Model.

The application analyzes the uploaded image, understands its visual content, and generates a comprehensive natural language description suitable for AI image generation models, prompt engineering, accessibility, and image understanding tasks.

Built with **Gradio**, the application offers a simple browser-based interface for seamless interaction.

#  Installation

Clone the repository

```bash
git clone https://github.com/RohithaKavala/image-to-prompt.git
```

Move into the project folder

```bash
cd image-to-prompt
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```
